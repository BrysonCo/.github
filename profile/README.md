# Benjamin Bryson software and applied AI portfolio

Selected software projects spanning applied AI, connected devices, desktop applications, and operational systems. My work combines product architecture, AI-assisted implementation, integration, review, testing, and delivery. These summaries describe the engineering work; implementation repositories are private.

## Ownce

**A user-owned application suite with local AI at its center.** Ownce is being built to replace a collection of paid and cloud-dependent applications with software and services the owner controls. The work spans application design, media playback, navigation, encrypted communication, infrastructure monitoring, and a substantial local knowledge system.

| Application | What the engineering covers |
|---|---|
| **Listen** | A music-library experience with album/artist discovery, compound genre/era search, playlists, favourites, listening history, original-file streaming, and queue/player controls. |
| **Watch** | A movie and television library with episode navigation, subtitles, resume/progress, contextual Up Next, personal lists, history, and playback preferences. |
| **Maps** | Interactive map layers, place search, route alternatives, guidance, saved places, and downloadable map-tile areas. |
| **Chat** | Native encrypted messaging implementation, attachments, verification/recovery foundations, durable sending, and explicit controls over AI participation. |
| **Network** | Device/client visibility, topology, WAN history, incident handling, notifications, and confirmation-based maintenance foundations. |
| **Knowledge & Library** | An owned reference collection with extraction/indexing, hybrid retrieval, source provenance, research dossiers, editable knowledge, and practical-task evaluation. |

Ownce develops its own application experiences and shared AI/control layer over appropriate open-source engines, including Navidrome, Jellyfin, Matrix, and MapLibre. The engineering challenge is to make the whole environment useful in daily life: carry context between applications, preserve ownership of data, and apply consistent access boundaries across independent services.

**Application versions:** Windows desktop and web implementations are joined by a native Android application with a phone-specific home, shared conversations, shortcuts, widget foundations, and handoff notes for the desktop. An iOS version is planned; native preparation is underway, with Mac/iPhone validation and distribution still ahead. Selected applications also have foundations for independent delivery.

**Current maturity:** This is an actively developed suite with substantial source implementation. Live-service and device qualification vary by app. Android has emulator evidence, while a verified Play release remains a separate step. Chat calling, full offline navigation, and a complete notebook-style knowledge interface remain ahead. Replacing comparable paid products is the product goal; complete parity across the suite is not claimed.

Engineering areas: typed Python services, TypeScript application interfaces, native clients, local inference, scoped tools and memory, media integration, retrieval, cross-device workflows, and automated verification.
